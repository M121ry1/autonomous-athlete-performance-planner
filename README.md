# Autonomous Athlete Performance Planner

## Phase 1

Phase 1 establishes synthetic data APIs for an autonomous
athlete-performance planning system.

## APIs

The system provides four synthetic data sources:

1. GPS / Workload API
2. Recovery API
3. Wellness API
4. Match Calendar API

## Technology

- Python
- FastAPI
- Uvicorn
- Pydantic
- NumPy
- Pandas
- Requests
